# Data Science Learning Repository

Welcome to this repository, a hands-on collection of Python notebooks, scripts, and mini-projects focused on data analysis, visualization, and practical machine-learning-adjacent workflows.

## Overview

This workspace brings together exercises and small projects built around popular Python libraries such as:

- NumPy
- Pandas
- Matplotlib
- Seaborn
- Plotly

It is designed for learning, experimentation, and building a strong foundation in data handling and visual storytelling.

## What’s Inside

The repository includes:

- Practice notebooks for core Python data libraries
- Mini challenges and exercises
- Data analysis scripts
- Visualization examples
- A small employee analytics project with CSV-based data exploration and graphs

## Project Structure

- Matplotlib/ — visualization practice and examples
- Matplotlib+Seaborn/ — combined plotting and styling projects
- numpy/ — NumPy exercises, notebooks, and small challenges
- pandas/ — Pandas practice and data analysis notebooks
- Plotly/ — interactive charting practice and dashboard examples
- Seaborn/ — statistical visualization examples and projects

## Technologies Used

- Python
- Jupyter Notebooks
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Plotly

## How to Use

1. Open the notebooks in Jupyter or VS Code.
2. Run the Python scripts to explore data processing and visualization examples.
3. Modify the examples to practice new ideas and build your own projects.

## Goals

This repository is meant to help you:

- Strengthen Python data-analysis skills
- Understand common libraries used in data science
- Practice building charts and dashboards
- Explore real-world-style data projects step by step

Many files are intended for learning and experimentation, so feel free to explore, adapt, and expand them.
